# Nexiq

A modern, full-stack **E-Commerce Platform** built with the **MERN Stack**. Nexiq delivers a seamless shopping experience with secure authentication, online payments, and a powerful admin dashboard.

## 🚀 Features

### 👤 User
- Secure Login & Registration (Email & Google OAuth)
- Browse, Search & Filter Products
- Product Details & Shopping Cart
- Order History
- Fully Responsive Premium UI

### 🛠️ Admin
- Dashboard with Sales Analytics
- Product Management (CRUD)
- Order Management
- User Management
- Cloudinary Image Upload

## 💻 Tech Stack

**Frontend**
- React 19
- Vite
- Tailwind CSS v4
- Shadcn UI
- Redux Toolkit
- React Router
- Axios
- Chart.js

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary


## 🌐 Deployment

- **Frontend:** Vercel / Netlify
- **Backend:** Render / Railway
- **Database:** MongoDB Atlas
